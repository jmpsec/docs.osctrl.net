The osctrl-admin component of **osctrl** provides an administration interface to interact with the enrolled nodes.

:::caution[Being deprecated]
The legacy server-rendered `osctrl-admin` HTML interface will be deprecated soon. The React frontend served alongside [osctrl-api](/components/osctrl-api/) is the primary operator experience going forward and will receive future UI improvements and features.
:::
